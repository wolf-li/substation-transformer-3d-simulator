# 防坑清单（多轮校准实战沉淀）

## 文件编辑

| 坑 | 后果 | 对策 |
|---|---|---|
| Python `str.replace` 默认替换**全部**出现 | 同名锚点多处命中，代码块被插到错误位置（如建模代码插进套管链导致 `ReferenceError`） | 锚点串必须含足够上下文保证唯一；或 `s.replace(old,new,1)` 且先 `assert old in s`；重要编辑后 `node --check` |
| 平台快照后文件变 root 只读 | `PermissionError` 写入失败 | `os.remove(p)` 后重写（同路径重建） |
| `node --check` 直接查 `.html` | `ERR_UNKNOWN_FILE_EXTENSION` | 正则提取 `<script type="module">` 内容写 `.mjs` 再查 |

## 无头验证

| 坑 | 后果 | 对策 |
|---|---|---|
| 模块未就绪就派发事件 | 型号切换静默丢失，截图是默认/旧模型 | 所有注入脚本先 `poll window.<Global>` 再动作 |
| 测试页结尾切回默认型号 | 截图与预期型号不符 | 截图用专用视角页，与回归页分离 |
| `--virtual-time-budget` 当就绪信号 | 长 sleep 掩盖真实加载错误 | 用显式就绪信号（全局对象/DOM 标记），加载错误应立即失败而非等待 |

## 几何与装配

- **悬空部件**：支撑柱长度必须算到目标面（盖面/柜底），逐件检查 y 范围；重建后全局搜一遍"支撑类"部件的端点坐标。
- **相交**：套管/附件排布先列出各附件的 x/z 占用区间再布点（如套管链要避开储油柜的 z 范围）。
- **比例凭感觉**：连续多轮"差不多"调整会累积偏差。每轮先用 PIL 从参考图量像素比例（盖以上高度/箱高、正面长宽比、部件间距），换算成模型坐标一次改到位。
- **部件语义**：先确认真实功能再建模（散热器下圆罐=ONAF 风扇、升高座=套管底座斜台），别按外形猜测。
- **共享部件条件化**：爬梯/铭牌/表盘等多型号共享的部件，位置要按规格表特征开关条件化（如 500kV 爬梯在右端、110kV 在左端）。

## 工作流

- 每轮只修一类问题：第 1 轮结构布局 → 第 2 轮贴合度（间隙/连接）→ 第 3 轮细节纹理。一轮混修易引入交叉错误。
- 差异清单化：比对后逐条列出"参考图有/模型无"与"位置/数量/角度错"再动手，避免遗漏。
- 交付前必跑 TESTLOG 回归，全部 PASS 且 ERRS=0 才保存版本。
